# Comptes rendus des travaux pratiques

## Lancer le site localement

1. Ouvrez un terminal dans le dossier `c:\Users\USER\chatti`
2. Exécutez `serve.bat`
3. Ouvrez `http://localhost:8000` dans votre navigateur

## Si vous voulez un hébergement public

- GitHub Pages : créez un dépôt avec ces fichiers et activez GitHub Pages dans les paramètres
- Netlify / Vercel : déployez ce dossier comme site statique

## Fichiers

- `index.html` : page principale
- `styles.css` : styles visuels
- `docs/` : vos fichiers PDF
